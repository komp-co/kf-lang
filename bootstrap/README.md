# Bootstrap seed

`komp.c` is a **checked-in, known-good C translation of komp**, generated by
komp compiling its own source. It is the seed that breaks the chicken-and-egg
of a self-hosted compiler: you can build komp from nothing but a C compiler,
without rkf or any existing kf toolchain.

```sh
cc -O2 bootstrap/komp.c -o komp
./komp bootstrap
```

## How it works

```
cc bootstrap/komp.c -> komp0     # the seed binary
komp0 builds compiler/komp/   -> stage1.c ; cc stage1.c -> komp1
komp1 builds compiler/komp/   -> stage2.c
assert stage1.c == stage2.c      # the fixpoint
```

The fixpoint (`stage1.c == stage2.c`, byte-for-byte) is the single test that
guards the entire compiler: if komp can no longer reproduce itself, this
fails. Run `komp bootstrap` in CI.

## Refreshing the seed

The seed only needs to be able to *build* the current source — it can lag.
Refresh it (and commit) when komp's source starts using a language feature
the current seed doesn't understand, or just to keep it current:

```sh
# from a working komp binary:
komp build komp -o bootstrap/komp.c
```

`komp bootstrap` fails when the checked-in seed is behind a fresh self-build.

## rkf

rkf (the original Rust bootstrap compiler, in the sibling `Rust/KFlat` tree)
is **no longer load-bearing** for building komp. It is kept only as a
*differential oracle* — a second independent implementation useful for
cross-checking codegen when hunting bugs. It is frozen, not retired.
